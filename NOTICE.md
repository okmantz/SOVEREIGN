# Notice

Sovereign is an independent implementation. It shares a *concept* with other "agent station" tools
(a floor plan that doubles as a permission and workflow graph) but contains **no code, artwork, sprites,
name or branding from any other project**. Characters are generated procedurally in `frontend/avatar.js`. Preset names describe archetypes (The Chemist, The Guide, Astronaut and so on) and are original pixel art, not reproductions of any specific character.

If you fork Sovereign, keep this file and the MIT license. The Sovereign name and logo are not trademarks
of anyone yet; pick your own if you ship a derivative.

Runtime dependencies: none (Node core modules only). Optional providers (OpenRouter, Ollama) are called
over HTTP with keys you supply.
